# 🚀 Novo Workflow - Sistema Simplificado

## O Que Mudou

### ❌ ANTES (Complexo)
- Formulário com 8+ seções
- Cliente preenche links, métricas, concorrentes...
- Parecia um questionário chato e longo

### ✅ AGORA (Simples)
- Formulário com **apenas 6 seções**
- Cliente preenche em **5 minutos**
- Envia **prints + links** facilmente
- Você faz a análise profunda baseado nos dados

---

## 📋 Novo Formulário Simplificado

**Localização:** `src/formulario-cliente-simples.html`

### 6 Seções (Apenas Essencial):

1. **Sua Empresa**
   - Nome
   - Segmento (select)
   - O que faz? (textarea curta)

2. **Redes Sociais**
   - Quais você usa? (checkboxes)
   - Links dos perfis (textarea)

3. **Objetivo para 90 Dias**
   - Qual é seu objetivo? (select)
   - Descreva sua meta (textarea)

4. **Concorrência**
   - Concorrentes principais (textarea simples)

5. **Tráfego Pago**
   - Quer investir? (select: sim/não/talvez)
   - Quanto por mês? (select - só aparece se sim)

6. **Prints e Imagens**
   - Upload de até 10 imagens
   - Drag and drop fácil

## 💼 Como Usar Este Sistema

### Para o Cliente (Sua Perspectiva):

1. **Abra o formulário:** `formulario-cliente-simples.html`
2. **Preencha em 5 minutos** (bem direto, sem tediosidade)
3. **Envie prints dos perfis** (upload fácil, drag and drop)
4. **Compartilhe os links** (Instagram, Facebook, etc)
5. **Pronto!** Você cuida do resto

### Para Você (Estrategista):

1. **Acesse os links que o cliente enviou**
2. **Analize prints dos perfis**
3. **Pesquise concorrentes** (que o cliente listou)
4. **Abra o template** `template-analise-completa.md`
5. **Preencha cada seção** com sua análise profunda e sincera
6. **Exporta como PDF** ou envia como markdown
7. **Entrega ao cliente** junto com apresentação (opcional)

## 📝 Dicas de Preenchimento do Template

### 1. Primeira Impressão
- Seja sincero: o que um visitante entende em 3 segundos?
- Cite o visual, consistência, clareza
- Aponte inconsistências

### 2. Pontos Fracos
- **Não suavize.** Se há problema, aponte
- Sempre proponha solução
- Explique impacto

### 3. Pilares de Conteúdo
- Máximo 4 pilares
- Cada um deve ser único e complementar
- Dê percentuais realistas

### 4. Plano de Ação
- 30 dias = mudanças rápidas (impacto alto)
- 90 dias = implementação estruturada
- Seja realista com prazos

### 5. Ideias de Conteúdo
- 50 posts: educativo, inspirador, produto, humor
- 20 reels: formatos virais, trending, rosto humano
- 30 stories: enquetes, bastidor, dicas, conexão
