## 🎨 Design e Customização

### Cores Atuais (Estília Style)
```css
--gold: #C9A86A        (Ouro)
--pink: #E8A0A0        (Rosa)
--cream: #FDFBF9       (Cream)
```

### Como Customizar
1. Abra qualquer arquivo HTML com editor de texto
2. Procure por `:root {` no CSS (no início)
3. Mude as cores para sua marca
4. Salve e reabra no navegador

Exemplo:
```css
:root {
  --gold: #YOUR-COLOR;
  --pink: #YOUR-COLOR;
  --cream: #YOUR-COLOR;
}
```
