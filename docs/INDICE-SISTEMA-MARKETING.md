## 🚀 DICAS DE OURO

### Para Bio Otimizada
1. Seja específico (não "consultoria")
2. Diga para quem (seu público ideal)
3. Mostre benefício (resultado, transformação)
4. CTA claro (demo, contato, link, etc)

### Para Pilares de Conteúdo
- Máximo 4 pilares
- Cada um deve ser único
- Juntos devem cobrir sua proposta
- Distribuição clara (%)

### Para Conteúdo Viral
- 70% Valor (educa, inspira)
- 20% Conexão (humor, história)
- 10% Venda (produto, promoção)

### Para Plano de Ação
- 30 dias = Mudanças rápidas (impacto alto)
- 90 dias = Implementação estruturada
- Seja realista com prazos
