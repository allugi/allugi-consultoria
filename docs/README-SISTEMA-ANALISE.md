# Sistema de Análise de Marketing Digital 📊

Um sistema completo para gerar consultoria profissional de marketing com o design elegante da Estília.

---

## 📋 Arquivos do Sistema

### 1. **formulario-cliente-marketing.html**
Formulário de coleta de dados do cliente com 8 seções:
- Informações da empresa
- Presença online (redes sociais)
- Bio e posicionamento atual
- Imagens/prints (links)
- Métricas atuais
- Análise de concorrentes
- Objetivos e metas
- Observações adicionais

**Como usar:**
1. Abra o arquivo no navegador
2. Preencha todos os campos com informações do cliente
3. Clique em "Salvar Dados e Gerar Relatório"
4. Os dados são salvos automaticamente no navegador (localStorage)

---

### 2. **analise-marketing-template.html**
Template do relatório final com 17 seções:

1. Contexto da Empresa
2. Primeira Impressão do Perfil
3. Bio e Descrição
4. Foto de Perfil
5. Destaques (Stories)
6. Análise do Feed
7. Estratégia de Reels
8. Pilares de Conteúdo
9. Análise de Posicionamento
10. Público Ideal
11. Estratégia de Monetização
12. Storytelling e Narrativa
13. Pontos Fracos
14. Oportunidades de Diferenciação
15. Plano de Ação
16. Banco de Ideias (50 posts, 20 Reels, 30 Stories)
17. Resumo Executivo

**Como usar:**
1. Preencha o formulário primeiro
2. Após salvar, clique em "Gerar Relatório"
3. Ou abra este arquivo e preencha manualmente os placeholders `[TEXTO]`

## 📝 Fluxo de Trabalho Recomendado

### Passo 1: Coletar Informações
```
Abra: formulario-cliente-marketing.html
Preencha todos os 8 seções com dados do cliente
```

### Passo 2: Fazer Análise Profunda
```
Baseado nos dados coletados:
- Analise as redes sociais do cliente (screenshots/links)
- Pesquise os concorrentes
- Identifique pontos fortes e fracos
- Defina estratégia personalizada
```

### Passo 3: Gerar Relatório
```
Abra: analise-marketing-template.html
Preencha cada seção com:
- Insights da análise
- Recomendações específicas
- Planos de ação
- Ideias de conteúdo
```

### Passo 4: Entregar ao Cliente
```
Exporte como PDF (Ctrl+P ou Cmd+P)
Compartilhe via email ou link
```

## 🔧 Dicas de Preenchimento

### Seção 2: Primeira Impressão
- Seja sincero e crítico
- Identifique o que funciona visualmente
- Aponte pontos que prejudicam a credibilidade

### Seção 8: Pilares de Conteúdo
- Máximo 4 pilares principais
- Cada pilar deve ser único e complementar
- Considere os 3-4 assuntos que realmente interessam ao público

### Seção 11: Monetização
- Customize os funils por rede social
- Leve em conta o público de cada plataforma
- Estratégias diferentes para cada estágio do funil

### Seção 13: Pontos Fracos
- Seja honesto mas construtivo
- Sempre proponha solução para cada problema
- Impacto = Como afeta o negócio

### Seção 15: Plano de Ação
- **30 dias:** Ações rápidas que geram impacto imediato
- **90 dias:** Implementação estruturada e planejada
- Seja realista com prazos

### Seção 16: Ideias de Conteúdo
- **50 Posts:** Mix de educativo, inspirador, produto
- **20 Reels:** Formatos virais + autoridade
- **30 Stories:** Interação + conexão + behind-the-scenes

## 📊 Estrutura de Análise Completa

### O que Analisar em Cada Rede Social

**Instagram:**
- Bio (clareza, CTA, autoridade)
- Feed (identidade visual, consistência)
- Reels (formatos, alcance, engajamento)
- Destaques (organização, relevância)
- Stories (frequência, tipo de conteúdo)
- Engajamento (comentários, DMs, salvos)

**Facebook:**
- Sobre (informações completas?)
- Posts (tipos, frequência, alcance)
- Comentários (comunidade engajada?)
- Reviews (rating, respostas)
- Eventos (se aplicável)

**TikTok:**
- Tipo de conteúdo (educativo? viral? autêntico?)
- Trending audios utilizados
- Durações ótimas
- Taxa de retenção
- Hashtags relevantes

**LinkedIn:**
- Headline (otimizado?)
- Sobre (proposta de valor clara?)
- Conteúdo (frequência, engajamento)
- Conexões relevantes (tamanho da rede)
- Articles/posts (autoridade)

**Google Meu Negócio:**
- Informações completas (horário, localização, fotos)
- Reviews (quantidade, rating, respostas)
- Posts/ofertas
- Fotos de alta qualidade
- Atualização frequente

## 💡 Recomendações Importantes

### Para Bio Otimizada
1. **Linha 1:** O que faz (máx 40 caracteres)
2. **Linha 2:** Para quem (máx 40 caracteres)  
3. **Linha 3:** Benefício principal
4. **Linha 4:** Call-to-action (link, contato, etc)

### Para Storytelling
- Sempre comece com um problema relatable
- Mostre a transformação/resultado
- Termine com um chamado à ação claro

### Para Conteúdo
- 70% Valor (educação, inspiração)
- 20% Conexão (história, humor)
- 10% Venda (promoção, produto)

## 🎯 Checklist de Análise

Antes de preencher o relatório, verifique:

- [ ] Todos os links de redes sociais foram verificados
- [ ] Screenshots/prints foram analisados
- [ ] Pelo menos 3-5 concorrentes foram pesquisados
- [ ] Taxa de engajamento foi calculada
- [ ] Público ideal foi claramente definido
- [ ] Pontos fortes e fracos foram identificados
- [ ] Oportunidades únicas foram descobertas
- [ ] Plano de ação é realista e executável
- [ ] Todas as 16 ideias de conteúdo foram preenchidas
- [ ] Relatório foi revisado antes de enviar

## 📱 Como Salvar como PDF

### No Navegador:
1. Abra o relatório preenchido
2. Pressione `Ctrl+P` (Windows) ou `Cmd+P` (Mac)
3. Selecione "Salvar como PDF"
4. Nomeie o arquivo: `[EMPRESA]-Analise-Marketing-[DATA].pdf`

### Dica de Qualidade:
- Selecione "Mais configurações"
- Ative "Gráficos de fundo"
- Escolha margem "Mínima"
