# 🎯 CONSULTORIA ALLUGI - Sistema de Análise de Marketing Digital

**Projeto Independente de Consultoria Estratégica de Marketing**

Um sistema profissional para análise completa de presença digital, posicionamento e estratégia de crescimento para empresas e marcas.

---

## 📊 O Que É Este Projeto?

Sistema completo de consultoria de marketing digital que combina:
- ✅ **Análise Profunda** — 17 seções de avaliação estratégica
- ✅ **Design Elegante** — Baseado em design de consultoria (Estília style)
- ✅ **Formulário de Coleta** — Dados estruturados do cliente
- ✅ **Relatório em HTML** — Exportável para PDF profissional
- ✅ **Exemplos Reais** — Template preenchido para referência
- ✅ **Documentação Completa** — Guias de uso e implementação

## 🚀 Quick Start (5 Minutos)

### 1️⃣ Ver um Exemplo
Abra no navegador: **`src/exemplo-relatorio-preenchido.html`**

Veja como fica um relatório completo pronto.

### 2️⃣ Começar com um Cliente
1. Abra: **`src/formulario-cliente-marketing.html`**
2. Preencha os 8 seções com dados do cliente
3. Clique em "Salvar Dados"

### 3️⃣ Fazer a Análise Profunda
- Visite os perfis do cliente (Instagram, Facebook, TikTok, LinkedIn, etc)
- Pesquise 3-5 concorrentes principais
- Identifique oportunidades e diferenciais
- Prepare recomendações estratégicas

### 4️⃣ Preencher o Relatório
1. Abra: **`src/analise-marketing-template.html`**
2. Preencha as 17 seções com suas análises
3. Revise antes de enviar

### 5️⃣ Exportar como PDF
`Ctrl+P` (ou `Cmd+P` no Mac) → Salvar como PDF

**Nome sugerido:** `[EMPRESA]-Analise-Marketing-[MÊS][ANO].pdf`

## 🎯 As 17 Seções de Análise

| # | Seção | Objetivo |
|---|-------|----------|
| 1 | Contexto da Empresa | Entender o negócio |
| 2 | Primeira Impressão | Diagnóstico inicial |
| 3 | Bio e Descrição | Análise de elementos-chave |
| 4 | Foto de Perfil | Recomendação visual |
| 5 | Destaques | Organização de stories permanentes |
| 6 | Análise do Feed | Identidade visual e consistência |
| 7 | Estratégia de Reels | Formatos que vencem |
| 8 | Pilares de Conteúdo | 4 temas principais |
| 9 | Posicionamento | Análise competitiva e diferenciação |
| 10 | Público Ideal | Segmentação e atração |
| 11 | Monetização | Funils de vendas por rede + tráfego pago |
| 12 | Storytelling | Narrativa e mensagem-chave |
| 13 | Pontos Fracos | Análise sincera do que prejudica |
| 14 | Oportunidades | Gaps no mercado a explorar |
| 15 | Plano de Ação | Prioridades 30 e 90 dias |
| 16 | Ideias de Conteúdo | 50 posts + 20 reels + 30 stories |
| 17 | Resumo Executivo | Síntese dos pontos-chave |

## 🎨 Design e Personalização

Todos os arquivos HTML usam o mesmo design elegante (Estília style):
- **Paleta:** Ouro, Rosa, Cream, Tons neutros
- **Tipografia:** Georgia (títulos) + Manrope (corpo)
- **Responsivo:** Mobile, tablet, desktop
- **Imprimível:** Otimizado para PDF

### Personalizar Cores
Edite no CSS de qualquer arquivo HTML:
```css
:root {
  --gold: #C9A86A;      /* Sua cor principal */
  --pink: #E8A0A0;      /* Sua cor secundária */
  --cream: #FDFBF9;     /* Seu background */
}
```
